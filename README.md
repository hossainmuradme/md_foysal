## Publish

Extract this ZIP; upload **all files and folders**, not the parent folder, to a GitHub repo. Go to Settings → Pages → Deploy from a branch → main → / (root). Site loads at `https://USERNAME.github.io/REPOSITORY/`. Preview locally by opening `index.html` or start `python -m http.server 8000`.

## Sources

Content is based on the user's 10 Google Sites PDF page exports, supporting individual certificates, and photos uploaded in chat (October 2026). Navy/teal styling follows the supplied Murad portfolio without reusing Murad's personal information. Genuine JPEGs and embedded PDF images are stored in assets/images as optimized WebP, and selected original certificate PDFs are in assets/docs.

## Adding certificates later

Save the new certificate JPG/PNG/WebP into `assets/images` and copy a `.certificate-card` block in `skills.html`, or a `.member-card` in `membership.html`. The page will grow automatically; no extra pages are needed.

## Editorial notes

Research projects are listed as projects/presentations, not peer-reviewed publications unless a verifiable bibliographic citation is provided. Where the original project poster was unavailable the page clearly notes this instead of using a misleading image. The DVM rank, GPA and selected work experience were transcribed from user's PDFs. Residential addresses/phone numbers and clinical case sheets are intentionally excluded from public GitHub version.
